# CH340 / CH341 USB 转串口驱动

开发板使用 **CH340**（USB 转串口）芯片。第一次在陌生电脑上插板子时，如果系统没装过驱动，
设备管理器会显示带黄色叹号的「未知设备」，串口无法识别，固件端也就扫不到 COM 口。

本目录提供安装驱动的文件，**推荐用一键脚本**：

## 方式一（推荐）：一键自安装脚本
1. 进入本目录，右键 `install_driver.bat` → **「以管理员身份运行」**
2. 脚本会把驱动 **预注册进系统驱动库**（`pnputil /add-driver ... /install`）
3. 之后 **任何 CH340 板子插上都会自动匹配驱动**，不再需要手动安装

> 为什么必须管理员？把驱动写进系统驱动库是受保护操作。
> 若系统没有 `pnputil`（很老的 Windows），脚本会自动改用 `CH341SER.EXE` 静默安装。

## 方式二：官方安装程序
直接双击 `CH341SER.EXE`，按向导点「安装」即可。命令行静默安装：`CH341SER.EXE /S`。

## 验证是否成功
插上板子，打开「设备管理器 → 端口 (COM 和 LPT)」，应出现形如 `USB-SERIAL CH340 (COMx)` 的条目。
固件端会自动扫描 CH340 所在 COM 口，无需手动指定。

## 文件说明
- `install_driver.bat` —— 一键安装脚本（推荐）
- `CH341SER.EXE` —— WCH 官方驱动安装程序（兜底）
- `raw/` —— 从已验证系统提取的原始驱动文件（inf/sys/cat/dll，带 WHQL 签名），供 `pnputil` 预注册使用
- `README.md` —— 本说明
