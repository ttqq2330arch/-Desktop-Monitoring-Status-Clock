# 离线对时（netclock）真机验证报告

日期：2026-09-20 09:05–09:16 ｜ 设备：ESP32-WROOM-32 DevKit V1 + ST7735S 128×160（COM7）
脚本：`esp32/tools/_verify_offline_clock.py --netsh tt112233`
固件：`firmware.bin` **931600 B**，md5 `30e6784fedbb34acb3d0df0326652c60`（Flash 70.6% / RAM 16.3%）

## 一、要验的是什么

设备**不接电脑**（插充电头）时，时钟页能不能自己拿到并显示正确时间。

之前的行为：设备只有收到 PC 推的 JSON 才会置 `gClkSynced`，不接电脑就**没有时间源**，
时钟页只会画 `NO DATA` —— 这不是显示 bug，是当时确实没时间。

现方案（`src/netclock.h/.cpp`）：PC 在线时完全不碰 WiFi；只有在**没有 PC 时间源**时才连
WiFi + SNTP 取一次；取到后**立刻 `WiFi.mode(WIFI_OFF)`**，成功一次 **6 小时**内不再重校。
WiFi 凭据只存 **NVS**，绝不进源码（本工程要开源导出）。

## 二、怎么模拟"脱离电脑"

真机脚本按顺序做：

1. 落 `pause.flag` + `schtasks /change /disable /tn PCMonitor` + `taskkill monitor.exe`
   → **让设备彻底失去 PC 数据源**
   （★必须连计划任务一起禁用：任务带 `-RestartCount 3`，光杀进程 1 分钟内会被拉起并抢走 COM 口）
2. 串口写入 WiFi 凭据 `WIFI:tt112233,***`（密码从本机 `netsh wlan show profile … key=clear` 读，
   **不落文件、不打印**）
3. **硬复位**（`RTS` 拉低再放开）→ RAM 清空、无任何时间源 = **等价于「插上充电头刚通电」**
4. 抓 60 秒串口日志
5. 恢复采集（删 flag + enable/run 计划任务）

## 四、过程中修掉的两个问题

### 1. 验证脚本自身误报（已修）

第一次跑报 `设备时间与 PC 相差 57.5s`，**那是脚本的锅**：57.5 s 正好等于
「SNTP 成功」到「脚本跑完」的采样时长 —— 脚本拿 **10.7 s 时刻取到的设备时间**去比
**脚本结束时（60 s 后）的 `datetime.now()`**，差值里混进了采样时长。
设备其实只差约 1 秒。

修法：采样起点记 `wall0 = datetime.now()`，把日志行的时间还原为
`当时PC时间 = wall0 + 该行相对秒数`，再比。改完后 `0.6 s / 1.4 s`，真实差异立刻显形。

> **通用铁律**：时间戳类判据必须把两侧对齐到「同一时刻」；另外，判据所依赖的现象
> 必须在被测固件里**有对应日志**（否则判据永远不成立）。

### 2. 烧录脚本隐患（已修）

`tools/_do_flash.py` 末尾"兜底拉起 monitor"指向 `pc/dist`（**构建输出**），
会与桌面部署那份同时跑、抢 COM 口。已改为优先拉桌面部署份。

### 3. 追加需求：只插电源不开机，一开机就是钟（已修 + 已验）

用户追加："没有连接电脑只是给他接上电源让它自动跳转时钟！"

第一轮实现是「6 秒门限后才跳钟、期间闪总览」——用户要的是**插电直接是钟、0 闪屏**。

- 改法：`curView` 初值 `VIEW_CLOCK`；新增 `gFirstOnlineDone`，**只有收到 PC 首帧**才升级到总览页
  （插着电脑约 1 秒后自然切总览，照常 10 秒轮播）。
- 踩坑（值得记）：第一版烧录后探针第一拍就显示 `view=0`。根因是 `online` 判定
  `millis()-lastPkt<=5000` 会让「上电头 5 秒 `lastPkt=0`」被**误判成在线**，把刚开机的设备
  错误拉去总览页 ⇒ 只插电源仍闪 6 秒总览才跳钟，等于白改。
- 修法：`online` 必须 `(lastPkt != 0) && (millis()-lastPkt<=OFFLINE_MS)`。
  只插电源时 `lastPkt` 恒为 0 ⇒ `online` 恒 false ⇒ 开机默认时钟页不被抢走。
- 二次烧录 + 验证：见上文第三节时间线 —— `view=1` 从首拍起、全程 `[1]`、`SNTP ok` 差 **0.5 s**、
  末条心跳差 **0.7 s**。
