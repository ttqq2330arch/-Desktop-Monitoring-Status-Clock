# 纵维立方（Anycubic）打印机局域网接入指南

> 适用：Kobra 2 / 2 Pro / X / 3 等带「局域网模式」的机型。
> 特点：**全程不需要账号密码**——凭据由程序自动向打印机索取，接上就能用。

---

## 一、接入三步（5 分钟搞定）

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① 开局域网模式 | 打印机屏幕：**设置 → 局域网模式 / LAN 模式**，打开开关 | 开一次即持久生效；开启后可能掉出云端 App，属正常现象 |
| ② 查打印机 IP | 打印机屏幕网络信息页，或登录路由器看设备列表 | 例：`192.168.1.16` |
| ③ 填配置 | 把 `pc/printers.json.example` 复制为同目录 `printers.json`，改 printer2 的 `ip` 和 `name` | 只填这两项，其余不动 |

改完重启采集程序（或重启电脑），屏幕打印机页 / 手机网页即显示实时状态。**没有第 4 步。**

```json
"printer2": {
  "enabled": true,
  "type": "anycubic_lan",
  "name": "Kobra X",        // 随便起名，屏幕顶栏显示（英文/数字）
  "ip": "192.168.1.16"      // ← 换成你打印机的 IP
}
```

---

## 二、"上电即连"是怎么做到的

程序**不预存任何凭据**，每次启动现场向打印机索取：

```
打印机上电（已开局域网模式）
   │
   ├─ GET  http://<ip>:18910/info          → 拿临时 token（明文 HTTP，免签名）
   ├─ POST /ctrl?ts&nonce&sign&did         → AES 密文（sign=MD5 链，密钥取自 token）
   ├─ 解密 → MQTT 账号/密码 + 客户端证书    ← 全自动，人不用碰
   └─ mqtts://<ip>:9883 连上，订阅 anycubic/#
```

连上之后两条数据通道并行：

| 通道 | 方式 | 内容 | 频率 |
|---|---|---|---|
| 进度/层数/文件名 | 打印机**事件推送** | `.../print/report` | 约 1 分钟 / 状态变化时 |
| 温度/风扇/状态 | 程序**主动查询** | `.../info` → 回复带热端/热床温度 | 每 30 秒 |

**断线自愈**：打印机断电再上电、网络闪断，程序按 3→6→12→…→60 秒退避自动重连，
重连时**重新发现凭据**（token 是一次性的，重发现是必须的）。人无需任何操作。

协议出处：Rinkhals 社区对 Anycubic 固件 MQTT 协议的逆向文档
（`rinkhals-community.github.io/Rinkhals/firmware/mqtt`）。

## 三、稳定运行的两个建议

1. **给打印机绑固定 IP**（重要）：路由器管理页 → DHCP 静态绑定，把打印机 MAC 绑到固定 IP。
   IP 一变程序就找不到了（凭据、证书都跟着 IP 走）。
2. **别开"仅云端"再切回来**：局域网模式开着时云端 App 看不到机器是正常的，两套通道二选一。

## 四、排错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 屏幕一直「无连接」 | 局域网模式没开 | 打印机屏幕检查开关 |
| 之前能用突然断了 | 打印机 IP 变了 | 路由器重新查 IP / 绑定静态 IP |
| 日志刷 `链路异常...重试` | 打印机刚上电还在启动 | 等它完全开机，1 分钟内自动接上 |
| 进度有、温度 `--` | 刚连上还没到查询点 | 最多等 30 秒 |
| 想手动验证链路 | — | `python pc/printers.py --dump`（源码工程内） |

## 五、代码位置（开发者）

| 文件 | 内容 |
|---|---|
| `pc/printers.py` → `AnycubicLAN` | 凭据发现（含纯 Python AES-128-CBC）+ MQTT 会话 + 主动查询线程 |
| `pc/printers.json(.example)` | 配置（真实文件含内网地址，不进仓库） |
| `tools/_anycubic_lan.py` | 独立诊断脚本（探测端口→取凭据→连 MQTT→监听） |
| `tools/_kx_query_info.py` | 单次温度查询验证脚本 |
| `esp32/src/main.cpp` → `drawPrinterPage` | 屏幕绘制（打印机页） |
