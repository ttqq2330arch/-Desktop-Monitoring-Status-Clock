PC 状态监控 · 操作手册

一个小小的桌面屏：显示电脑运行状态（CPU / 内存 / 显卡 / 天气）， 还能顺便显示最多两台 3D 打印机的实时进度。装好之后什么都不用管，开机自动运行。

一、开始前 30 秒检查

检查项要求
电脑系统Windows 10 / 11（64 位）。Win 8.1 可用，Win 7 不行
WiFi家里要有 2.4G WiFi（几乎都有；只有 5G 的穿墙王路由要看清名字，5G 的连不了）
USB 线给屏幕盒子供电的线必须能传数据（纯充电线不行）
手机连家里同一个 WiFi（最后一步看状态用）

二、安装（一共就三步，约 5 分钟）

1
解压

把 PC监控礼盒.zip 解压出来：右键 → 全部解压缩（或用 7-Zip / WinRAR）。 解压后把整个文件夹放到本地硬盘（比如 D:\PC监控礼盒）。 不要在 U 盘里直接运行；路径里尽量别有奇怪符号。

2
双击「一键安装.bat」

会自动做四件事：装 USB 驱动 → 注册开机自启 → 启动采集程序 → 自检。

这两个弹窗是正常的，别慌：
① 蓝色「Windows 已保护你的电脑」→ 点 更多信息 → 仍要运行
② 杀毒软件报毒 → 选 允许 或加白名单 （程序是打包生成的，杀软经常误报；不放心可以先让杀软扫一遍）
③ 弹出「用户账户控制」要管理员权限 → 点 是
成功标志：黑窗口最后显示采集程序日志几行、不报错，然后自动弹出本手册。
3
用 USB 线把屏幕盒子插到这台电脑，双击「配WiFi.bat」

按提示输入家里的 WiFi 名称和密码（就是手机连的那个 2.4G WiFi）。

成功标志：窗口最后出现大字 配网成功！手机浏览器打开 http://192.168.x.x。
工具会自动认出屏幕插在哪个口；如果让你从列表里挑一个， 选描述像 USB-SERIAL CH340 或 USB 串行设备 的那个。
完成！屏幕亮起显示数据；手机连同一 WiFi，浏览器打开上面那个 http://192.168.x.x 地址，就能在手机上看到同样的页面。

三、接 3D 打印机（可选，不接不影响电脑监控）

纵维立方（Anycubic Kobra 系列）→ 屏幕第 5 页

#操作
1打印机屏幕：设置 → 局域网模式，打开（开一次就一直生效）
2查打印机的 IP（打印机屏幕的网络信息页，或登录路由器看设备列表）
3把 printers.json.example 复制一份，改名 printers.json，用记事本打开， 改 printer2 那段的两行：
"name": "Kobra X"（随便起名，英文数字）
"ip": "192.168.1.50"（换成打印机的 IP）
4双击「恢复采集.bat」。完事，屏幕和手机上都能看到打印进度

创想（K1 / Ender-3 V3 等 Klipper 机型）→ 屏幕第 4 页

#操作
1确保打印机的联网功能已开启（Klipper / Moonraker），查到 IP
2同样复制改 printers.json，改 printer1 段的 "ip" （type 和端口 7125 都不用动）
3双击「恢复采集.bat」
强烈建议：在路由器里给打印机（和屏幕盒子）绑定固定 IP （DHCP 静态分配）。IP 一变就连不上了，这是「之前好好的突然断了」的头号原因。

四、遇到问题？对照这张表

症状原因与解决
双击 bat 一闪就没了 被拦截了。右键 bat → 属性 → 勾选「解除锁定」→ 确定，再双击； 或按手册第 2 步处理 SmartScreen / 杀软弹窗
屏幕一直停在 PC MONITOR 不出数据 电脑没认出串口。设备管理器里应有 USB-SERIAL CH340 (COMx)； 没有就双击 drivers\CH340\install_driver.bat 装驱动，装完拔插一次 USB。 还不行换一根数据线
配网时提示找不到串口 / 让挑串口 按窗口里的列表选屏幕盒子所在的口（认 CH340 或 USB 串行设备 字样）；没有列表说明驱动没装好或线是充电线
配网 30 秒没成功 ① 名称或密码输错 → 重跑「配WiFi.bat」再试； ② WiFi 是 5G → 换 2.4G；③ 信号太弱 → 把设备挪近路由器
手机打开 pcscreen.local 没反应 安卓手机多数不认这个域名，正常——用配网工具最后显示的 http://192.168.x.x IP 地址访问。IP 变了就重新跑一次配网工具看新 IP， 或在路由器里绑固定 IP
之前能用，突然连不上了 九成是打印机/屏幕的 IP 被路由器换了 → 路由器里重新查 IP 并绑固定， 改 printers.json 后双击「恢复采集.bat」
打印机页温度显示 -- 刚连上的 30 秒内还没查到温度，等一下就有；一直 -- 说明打印机 没在打印且待机降温了，属正常
天气显示 NO DATA 天气需要联网（自动按 IP 定位）。WiFi 没配好或家里断网时正常现象
想改 WiFi / 换路由器了 重新跑一遍「配WiFi.bat」即可，设备支持存多组 WiFi
打印机开了局域网模式后手机 App 看不到它了 正常现象：局域网模式和云端二选一。本系统走局域网，不受影响
想搬家 / 换电脑 / 不用了 双击「卸载.bat」删掉开机自启，再把文件夹删了即可，无残留

五、日常使用与包内文件

装好后什么都不用管：开机自启、拔了屏幕自动等待、再插自动重连。

文件用途
一键安装.bat第一次安装用（只跑一次）
配WiFi.bat配 / 改 WiFi，或想重新看设备 IP 时
暂停采集.bat / 恢复采集.bat手动停 / 起后台程序（占串口的场景用）
烧录固件.bat + firmware 文件夹重刷设备固件（出厂已烧好，一般用不到）
printers.json.example打印机配置模板（复制改名 printers.json 后改两行）
卸载.bat删除开机自启
